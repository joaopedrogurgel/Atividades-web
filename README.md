# Atividades de Web

Repositório destinado ao armazenamento das atividades e exercícios desenvolvidos durante as aulas de **Desenvolvimento Web**.

## 📚 Conteúdo

Os arquivos deste repositório correspondem às atividades realizadas ao longo da disciplina, envolvendo diferentes conceitos e tecnologias relacionados ao desenvolvimento web.

## 🎓 Objetivo

Organizar e registrar os exercícios, trabalhos e práticas desenvolvidos durante as aulas, acompanhando o aprendizado ao longo da disciplina.
